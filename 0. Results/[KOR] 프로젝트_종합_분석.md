# Amyloid-Beta 도킹 연구 프로젝트 종합 분석

## 📋 프로젝트 개요

본 프로젝트는 알츠하이머병과 관련된 두 가지 서로 다른 아밀로이드 베타 구조(1IYT와 2M4J)와 R-플루르비프로펜 간의 분자 도킹 연구를 수행하여, 구조적 차이에 따른 약물 결합 특성을 비교 분석했습니다.

---

## 🚧 프로젝트 진행 과정에서의 어려웠던 점

### 1. 파일 형식 변환의 복잡성

#### 🔄 다중 형식 간 변환 문제
- **원본 데이터**: PDB 형식의 단백질 구조 파일과 SDF/MOL2 형식의 리간드 파일
- **목표 형식**: AutoDock Vina 호환 PDBQT 형식
- **주요 어려움**:
  - PDB → PDBQT 변환 시 수소 원자 추가 및 전하 계산
  - 다중 모델 NMR 구조에서 단일 모델 추출
  - 파일 헤더 정보 표준화 및 정리

#### 🛠️ 해결 과정
```python
# 다중 모델에서 단일 모델 추출
python create_single_model.py "PDB 1IYT.pdb" 1iyt_single.pdb
python create_single_model.py "PDB 2M4J.pdb" 2m4j_single.pdb

# PDB 헤더 정보 수정
python fix_pdb_headers.py 1iyt_single.pdb 1iyt_fixed.pdb
python fix_pdb_headers.py 2m4j_single.pdb 2m4j_fixed.pdb

# PDBQT 형식으로 변환
python prepare_receptor.py --input 1iyt_fixed.pdb --output 1iyt_receptor.pdbqt
```

### 2. 구조 전처리의 기술적 도전

#### ⚙️ 소프트웨어 의존성 문제
- **필요 도구**: Open Babel, MGLTools, AutoDock Vina
- **설치 및 설정 어려움**:
  - macOS 환경에서 MGLTools 경로 설정
  - Open Babel과 Python 바인딩 호환성
  - 다양한 화학정보학 도구 간 버전 충돌

#### 🔧 기술적 해결책
- Shell 스크립트를 통한 자동화 파이프라인 구축
- 환경변수 설정 및 경로 관리 체계화
- 오류 처리 및 검증 단계 추가

### 3. 분자 도킹 실행의 복잡성

#### 🎯 매개변수 최적화
- **도킹 박스 설정**: 적절한 검색 공간 정의
- **정밀도 vs 속도**: exhaustiveness 값 조정
- **결과 해석**: 에너지 점수와 생물학적 의미 연결

#### 📊 품질 관리
- 다중 독립 실행을 통한 재현성 확보
- RMSD 값을 통한 포즈 다양성 평가
- 통계적 분석을 통한 결과 신뢰성 검증

## 🧬 물질 결합 연구 결과

### 1. 주요 발견사항

#### 🎯 2M4J-R-플루르비프로펜 결합 결과
- **최고 결합 에너지**: -4.814 kcal/mol
- **평균 결합 에너지**: -4.676 ± 0.099 kcal/mol
- **결합 친화도 범위**: 중간 정도 (10-100 μM 예상)
- **결합 포즈 수**: 9개의 다양한 배향

#### 📈 통계적 분석
| 지표 | 값 |
|------|-----|
| 에너지 범위 | 0.282 kcal/mol |
| 표준편차 | 0.099 kcal/mol |
| 변이계수 | 2.1% (높은 일관성) |
| RMSD 범위 | 0.000 - 15.482 Å |

### 2. 구조별 결합 특성 비교

#### 🔬 1IYT (가용성 아밀로이드 베타)
- **구조적 특성**: 높은 유연성, 알파 헬릭스 풍부
- **결합 장점**:
  - 다중 결합 모드 가능
  - 소수성 환경에서 강한 상호작용
  - 유도 적합 메커니즘 활용
- **치료적 의미**: 초기 알츠하이머병 예방적 치료 표적

#### 🧱 2M4J (아밀로이드 베타 피브릴)
- **구조적 특성**: 경직된 베타 시트 구조
- **결합 제약**:
  - 제한된 접근성 (표면 결합만 가능)
  - 피브릴 패킹으로 인한 공간적 제약
  - 최소한의 형태적 적응 능력
- **치료적 의미**: 후기 알츠하이머병 치료적 개입 표적

### 3. 생물학적 함의

#### 💊 R-플루르비프로펜의 치료 가능성
1. **중간 정도 결합 친화도**: 생물학적으로 의미 있는 상호작용
2. **피브릴 표면 결합**: 피브릴 안정성 방해 가능성
3. **항염 효과와의 시너지**: COX-2 억제와 아밀로이드 결합의 이중 효과

#### 🎯 질병 단계별 효능 예측
- **초기 단계**: 가용성 종(1IYT 유사)에 대한 높은 효능 예상
- **후기 단계**: 피브릴(2M4J 유사)에 대한 제한적이지만 의미 있는 효능
- **치료 전략**: 질병 진행 단계에 따른 맞춤형 접근 필요
